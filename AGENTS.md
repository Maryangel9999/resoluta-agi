# RESOLUTA FINANCE

Aplicativo financeiro para microempresas e pequenos negócios, desenvolvido como vertical financeira da RESOLUTA AGI.

## Visão geral

Este projeto é a base inicial do app RESOLUTA FINANCE, com identidade visual institucional, navegação funcional, dashboard e módulos iniciais de:

- Visão geral
- Movimentações financeiras
- Análise financeira
- Formação de preço
- Produtos e serviços
- Aprenda
- Planos FREE e PRO
- Configurações
- Perfil e conta

## Stack recomendada

- React + TypeScript + Vite
- React Router
- CSS puro com design system próprio
- Persistência inicial localStorage
- Preparação para Supabase/PostgreSQL em evoluções futuras

## Como executar

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Observações importantes

- Nesta fase inicial, a persistência é local e orientada para prototipagem funcional.
- A arquitetura já foi preparada para evoluir para autenticação e banco persistente seguro.
- Não há autenticação real ou dados multiusuário nesta etapa inicial.
