# AGENTS.md

## Objetivo

Este repositório concentra a base arquitetural e visual do aplicativo RESOLUTA FINANCE.

## Diretrizes

- Preserve a identidade da marca RESOLUTA AGI.
- Priorize qualidade de código, acessibilidade e clareza financeira.
- Mantenha a navegação funcional e os módulos executáveis.
- Evite simular integrações reais quando não houver backend ou autenticação implementados.
- Documente limitações de persistência, segurança e infraestrutura.

## Fluxo de desenvolvimento

1. Ajustar a funcionalidade em branch específica.
2. Validar build e estrutura relevante.
3. Atualizar documentação quando houver mudança relevante.
4. Nunca declarar conclusão sem verificar o que foi realmente implementado.
